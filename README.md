# Jannah Choir — Website

A small, responsive, ad-free social links page for Jannah Choir.

## Preview locally
Open `index.html` in a browser. The logo is in `assets/jannah-choir-logo.jpg`.

## Publish free with GitHub Pages
1. Sign in to GitHub and create a new **public** repository, e.g. `jannah-choir`.
2. Upload `index.html` and the `assets` folder (keep the folder structure).
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then Save.
6. Wait for GitHub to publish the site. Your public address will appear in the Pages section.
7. Open that address on your phone and test all three buttons before making a QR code.

The page is static: GitHub hosts it continuously, so your own computer does not need to stay on.
